KakaoTalk Notifier for Home Assistant

Before logging in, register a Redirect URI in the Kakao Developers console. If you opened this page at the Home Assistant address you entered in the integration settings, it is:

Open https://developers.kakao.com/, select your app, then go to App > Platform Key > REST API key > Redirect URI.
The registered URI must be exactly your Home Assistant address (redirect_uri) followed by /api/kakao_talk.

To log in: in Home Assistant, go to Developer tools > Actions and run kakao_talk.login as an administrator. A notification appears with a single-use login link that expires in 10 minutes. For security, a login cannot be started from this page.

KakaoTalk login complete.

Messages are sent to the account you just logged in with. To switch accounts, run the kakao_talk.login action again and log in with the other account.
