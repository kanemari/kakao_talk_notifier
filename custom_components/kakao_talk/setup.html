KakaoTalk Notifier for Home Assistant

Originally by clipman, updated for current Home Assistant and Kakao APIs.

Before logging in, register this URI as a Redirect URI in the Kakao Developers console:

Open https://developers.kakao.com/, select your app, then go to App > Platform Key > REST API key > Redirect URI.
This URI must match the redirect_uri in your configuration.yaml (plus /api/kakao_talk).

KakaoTalk login complete.

Messages are sent to the account you just logged in with. To switch accounts, log in again with the other account.
